# 04 中国政策公告（经理要求，2026-11-26 起）

> 每天跑一次（不按公司分），使用网页搜索。窗口与当天报告相同：北京时间 {start} 至 {end}。
> 经理原话："focus on policy announcements by CCP. Anything on data centre, hardware, tech, AI, robotics."

【范围】
中央和部委层面发布、批准或公开征求意见的政策、规划、通知、标准、法规、会议部署，主题限于：
- 数据中心、算力（含"东数西算"、算力网络、智算中心、数据中心能耗/绿电/PUE 要求）
- 硬件与半导体（芯片、设备、材料、存储、服务器、光通信、国产替代、首台套）
- 科技综合（科技自立自强、新质生产力、数字经济、出口管制及反制、科技类关税/补贴）
- 人工智能（"人工智能+"行动、大模型备案与监管、AI 应用、AI 安全、数据要素）
- 机器人（人形机器人、具身智能、工业机器人）
- 与以上相关的新能源汽车、电池、储能政策（与组合里宁德时代、小米、禾赛有关的）

【来源】（只用一手或官方媒体，不用自媒体解读）
- 中共中央、国务院（gov.cn）、中央政治局会议、中央经济工作会议、中央财经委员会会议、全国人大常委会
- 部委：国家发改委、工信部、科技部、财政部、商务部、国家数据局、国家网信办、市场监管总局、海关总署、国资委、证监会
- 新华社、人民日报、央视新闻、经济日报对上述机构的权威发布
- 地方政府（北京、上海、深圳、广东、浙江、江苏等）只收**有具体金额或明确补贴、采购安排**的
- 外国对华科技政策（如美国出口管制新规）不在此列，除非中国官方有回应或反制

【每条要查清】
- 发布机构、文件名称、文号（如有）、发布日期；是正式发布、批准，还是征求意见稿
- 强制还是指导性；生效日期
- 有没有具体金额、补贴、税收优惠、采购或配额安排、目标数字（如"到 2027 年算力规模达到 X EFLOPS"）
- 有没有点名或明显指向某类、某家企业受益或受限（套用 02_impact.md 的"政策、行业标准、产业规则类新闻"规则：有实证才算偏向）
- 是新政策，还是旧政策的重复表述（旧政策重复的不要列；不确定的注明）

【影响判断】
对照 data/companies.yaml 和 data/portfolio.yaml，写明影响哪些在跟踪/组合里的股票、通过什么路径（客户、供应商、竞争、主题情绪）。
等级标准沿用 02_impact.md。泛泛的口号、会议表态、没有数字和抓手的文件，一律"低"。

【输出格式】

```
### 政策 N：<一句话标题>
- 发布机构 / 文件：<名称，文号>
- 发布时间：YYYY-MM-DD HH:MM（北京时间）
- 性质：正式发布 / 批准 / 征求意见稿；强制 / 指导性；生效日期
- 链接：<URL>；另见：<…>
- 事实摘要：<只写原文明确写了的，保留数字>
- 影响分析：
  - 相关股票：<股票（代码）>：<高/中/低/无> · <方向> · <传导路径> —— <为什么>
  - 板块情绪：<板块>：<程度> · <方向>
  - 是否有实证偏向特定公司：<有，证据是… / 无>
  - 综合等级：<高/中/低/无>
- **English**：<按 03_summary_en.md 的写法，一段可直接粘贴的英文，不写等级标签>
```

整个窗口没有相关政策的，写"本时段未找到相关政策公告"。
所有条目之后列"未找到"：数据中心、硬件/半导体、科技综合、AI、机器人，各写有无。
