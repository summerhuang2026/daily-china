# 02 影响分析（对应原 2.3）

> 输入：01 步骤输出的 {cn_name} 新闻条目；data/portfolio.yaml（整个组合，含每只股票的业务和主题）。
> 只能根据 01 的新闻条目分析，不要再搜索新信息，不要引入 01 里没有的事实。

请对每一条新闻，分析它对 {cn_name}（{tickers}）本身、对组合中其他股票（特别是股价）、以及对市场情绪的影响和程度，并解释为什么。

## 影响程度标准

**对本股（股价）**
- **高**：可能改变市场对未来 1–2 年盈利的预期，或可能引起单日股价 ±5% 以上。
  例：业绩明显超/低于预期；订单约占年营收 10% 以上；核心药物/产品获批或临床失败；制裁、监管处罚；重大并购；CEO/董事长变动；回购约占总股本 2% 以上。
- **中**：影响某条业务线或短期预期，可能引起 ±2%–5%。
  例：订单约占年营收 3%–10%；新品有明确客户或出货量；有具体金额的产能扩张；竞争对手重大价格调整；月度数据明显偏离趋势；回购约占总股本 0.5%–2%。
- **低**：例行信息、已在预期内、或缺乏数字支撑，±2% 以内。
  例：展会展示、管理层泛泛表态、小额回购。
- **无**

**对组合中其他股票**：同样四档，但必须写明传导路径——客户 / 供应商 / 竞争对手 / 同一主题情绪（用 portfolio.yaml 里的 themes 判断）。说不出传导路径的，一律算"无"，不要列出。

**对市场情绪**：高 / 中 / 低，并写明是哪个板块（如港股创新药、A股AI光模块、锂电）。

**每条影响都要标注**：
- 方向：正面 / 负面 / 中性 / 不确定
- 依据：事实（新闻直接说明）/ 推断（你的分析）

**回购**：用 data/companies.yaml 的 shares_outstanding 估算回购股份占总股本的百分比，写出算式，并说明这个比例为什么有（或没有）影响。shares_outstanding 为空时，写"总股本未知，无法估算"。

## 输出格式

对 01 中的每一条新闻（编号与 01 一致）：

```
#### 影响分析（新闻 N）
- 对本股：<高/中/低/无> · <方向> · <事实/推断> —— <为什么，2–3 句>
- 对其他股票：
  - <股票名（代码）>：<程度> · <方向> · <传导路径> —— <为什么，1–2 句>
  - （没有则写"无明显影响"）
- 对市场情绪：<板块>：<程度> · <方向> —— <为什么，1 句>
- 综合等级：<高/中/低/无>（取以上三项中最高的一项）
```

不要因为想"有内容"而抬高等级。大多数日常新闻是"低"，这是正常的。
