# 05 小白解读 + 发群建议（帮用户自己学会判断）

> 输入：同一条新闻的 01 事实、02 影响分析、03 英文段落；feedback.md（经理和同事的历史反馈）。不再搜索。
> 读者是用户本人：不是金融专业出身，需要用大白话看懂新闻，并逐步学会自己判断要不要发群。

对每一条新闻（含政策条目），输出：

```
**🔎 小白解读**：<1–3 句大白话：这条新闻在说什么，跟这只股票有什么关系。不要用术语；非用不可的，下面解释>
**📘 名词**：<本条出现的专业名词，每个一句话解释，如"ASP：平均售价，一台手机平均卖多少钱"。没有写"无">
**✅ 建议**：<发群 / 合并后发群（与新闻 X 合并）/ 不发 / 转医药同事> —— 对应下面第几条规律，一句话说明
```

## 判断规律（来自 feedback.md，经理和同事的实际反馈；规律有更新时以 feedback.md 为准）

**发群（经理认为重要、有意义）**
1. 业绩、业绩会、业绩说明会：有具体数字，能改变盈利预期。
2. 有"角度"的行业或供应链消息：一条消息能牵出组合里另一只股票，且不是显而易见的联系（例：手机厂下调出货目标 → 联发科）。
3. 股价大涨大跌，**同时有基本面原因**（例：宁德时代大跌，背后是减产报道和去库存）。
4. 地方政府的具体政策：有数字、补贴、目标，可以顺着找当地公司（例：广东十五五算力规划）。
5. 竞争格局和产业链布局的动作（入股关键设备商、竞争对手新品放量）；同一主题的几条 → 合并后发群。
6. 观察名单里的公司（companies.yaml 中 group: watchlist，如恒瑞医药）的业绩和重大进展。
7. 政策或标准**有实证**表明偏向某些公司。

**不发**
1. 纯行情和资金流：涨跌幅、成交额、主力资金、板块轮动，没有公司新闻或基本面原因（经理："useless market information… not investment worthy"）。
2. 国家层面的泛泛政策：口号、会议表态，没有数字和抓手（经理："太虚了"）。
3. 政策或标准没有实证表明偏向某家公司。
4. 已知信息：群里已经发过的，或旧闻重提。若只有部分重合，建议写"quote 群里那条，只发增量"。
5. 小事：小额回购、展会、营销内容、管理层泛泛表态。

**转医药同事**
- companies.yaml 中 route: 医药同事 的公司（信达、药明康德、药明合联、康方、英矽智能、恒瑞），以及其他医药类新闻：一律建议"转医药同事"，由他判断。
- 若同时满足上面"发群"的第 1 条（业绩），写"转医药同事；业绩类，可能也值得发群"。
- 参考同事标准：小样本、早期（I/II 期）、罕见病的临床数据只算"值得留意"；关键的大型 III 期结果才重要。

**写法提醒**：建议发群的，英文段落就是 03 的那段；若建议合并，在建议里写出与哪条合并。
