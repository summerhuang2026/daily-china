# 01 中文信息搜集（对应原 2.2）

> 本模板中 `{...}` 由运行流程从 data/companies.yaml 和当天时间窗口自动填入。

【背景】
- 公司：{cn_name}（{en_name}，{tickers}），主营：{business}。
- 事件：{event}
- 注意：不要与{confusable}混淆。

【时间与来源要求】
- 只用北京时间 {start} 至 {end} 发布的信息。
- 找不到发布时间的：如果内容看起来可能在时段内，照样列出，发布时间写"无时间戳（待人工判断）"，并写下你判断的依据（如 URL 日期、正文提到的日期）。明显是旧闻的不要列。
- 优先使用以下一手来源（清单外的媒体也可以用，但要标明出处）：
  - 中文媒体：{media}。
  - 公司公告：{filings}。
  - 公司官网（{website}）的中文新闻稿。
  - 公司自己发布的公告和新闻稿，**中文或英文都算一手来源**：交易所公告、官网投资者关系页面、PR Newswire / GlobeNewswire / Business Wire 上的公司发稿。英文的写明"公司英文发稿"。
- 不要用外媒报道的中文转译稿（这里指第三方媒体，不包括公司自己的英文发稿）。

【每次必查清单】（找不到的写"未找到"）
- 指数纳入或剔除（恒生指数系列、恒生科技、MSCI、富时、沪深300、科创50等）。
- 港股通纳入或调出。
- 限售股解禁、配售、增发、可转债。
- 交易所或监管机构对公司的问询、处罚、调查。
- 中国或者国外券商的评级和目标价不需要。
- 涉及政策、行业标准、产业规则的新闻：额外查清并写进事实摘要——强制还是推荐/自愿；谁批准、谁牵头起草、哪些公司参与；生效日期；有没有配套认证或认证机构；有没有客户在采购或招标中要求符合；有没有点名受益公司、补贴或限制某类（含外国）供应商的条款。查不到的写"未找到"。
- 同一内容被多家转载的，只列原发媒体，其余合并为"另见"。

【请回答】
1）经营数据：例如季度营收、利润、毛利率；月营收及同比、环比。

2）管理层的战略和意向（以财报电话会、法说会和媒体采访为准）：
   - 对指引、价格策略、毛利率的表述。
   - 海外市场、新客户或订单、产能扩张的计划。
   - {key_new_business}的规划。
   - 回购、分红等资本动作。
   - 请区分"已执行"和"计划或考虑"。

3）竞争对手的动作：
   - 主要竞争对手，包括但不限于{competitors}。
   - 此期间的公开表态、新品发布、客户或订单公告、价格调整、股价反应。
   - 若某家公司在此期间没有相关动态，直接写"未找到"，不要用旧闻填充。

3b）行业与供应链消息（非公司官方，但中国媒体有报道的）：
   - 中国媒体援引供应链、产业链人士、知情人士或第三方机构（如 Counterpoint、IDC、TrendForce、Canalys、中国汽车动力电池产业创新联盟等）报道的、**同时涉及本公司和同行**的行业数据：
     出货/销量/交付目标或计划、上调或下调目标、砍单或加单、备货、产能计划、价格调整、市场份额排名。
   - 典型例子：多家手机厂（小米、苹果、三星、OPPO、vivo、华为等）同时下调明年出货目标；多家电池厂的装机量排名；光模块厂的订单或备货变化。
   - 状态写"市场消息（非公司官方）"，原发来源写清是哪家媒体、援引谁。本公司或在跟踪的同行如有官方否认或回应，一并列出。
   - 涉及本公司的数字（如本公司的目标、份额）要放在事实摘要第一句；同时把同行的数字一起列出，方便比较。
   - 没有的写"未找到"。

4）关联公司动态（companies.yaml 里有 related 字段时才做，没有就整段删掉）：
   - 关联公司：{related}。
   - 用它的 search_terms 搜索中文和英文信息：融资、新品发布、客户或订单、量产、人事变动，以及与本公司的合作或交易。
   - 分析时说明它和本公司的关系（例如创始人重叠、技术合作），以及这条消息对本公司有什么影响。
   - 没有动态的，写"未找到"。

【输出格式】（固定格式，后续步骤和以后换成 DeepSeek 都依赖它）

按"新闻条目"逐条列出，每条一个小节：

```
### 新闻 N：<一句话标题>
- 类别：经营数据 / 管理层战略 / 竞争对手（<对手名>） / 行业与供应链消息 / 关联公司（<名称>）
- 发布时间：YYYY-MM-DD HH:MM（北京时间）／ 无时间戳（待人工判断）：<依据>
- 原发来源：<媒体或公告名称>（不在优先清单内的，加注"清单外"）
- 链接：<URL>
- 另见：<其他转载媒体，没有写"无">
- 状态：已执行 / 计划或考虑 / 市场消息（非公司官方） / 不适用
- 事实摘要：<只写来源里明确写了的事实，保留原始数字，不加评论>
```

所有条目之后，加一个"未找到"小节，逐项列出没有找到信息的部分：
1）经营数据、2）中的每一小项、3）中的每一家竞争对手、3b）行业与供应链消息。

规则：
- 每条事实都要有链接。找不到链接的，不要写。
- 数字照抄原文，不换算，不四舍五入。
- 整个窗口里都没有任何新闻的，只输出"本时段未找到相关信息"和"未找到"小节。
